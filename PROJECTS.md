### 01 · LEO.AI — Civic assistance

<img alt="LEO.AI project banner" src="https://raw.githubusercontent.com/svsramakrishnanaidu-rgb/leo-ai/main/docs/assets/leo-banner.svg" width="100%"/>

**Problem:** People reporting potholes, waste problems, streetlights or leaks may need help describing a problem clearly and finding the relevant department.

**Approach:** A multilingual AI-assisted civic issue reporting *prototype* with a guided complaint builder, optional AI categorization, local fallback, map exploration, tracking experience, and analytics dashboard.

**Technology:** React · TypeScript · Tailwind CSS · Vite · Framer Motion · Leaflet · Recharts · optional Groq API

**Data status:** Browser-local records and illustrative demonstrations; **not** an official government reporting service or municipal tracking system.

[**Website →**](https://leo-ai-pi.vercel.app/) · [Source code →](https://github.com/svsramakrishnanaidu-rgb/leo-ai) · [Documentation →](https://github.com/svsramakrishnanaidu-rgb/leo-ai#readme)

### 02 · FinTrack — Premium expense tracker

<img alt="FinTrack project banner" src="https://raw.githubusercontent.com/svsramakrishnanaidu-rgb/fin-tracker/main/docs/fintrack-banner.svg" width="100%"/>

**Problem:** Daily expenses are easy to forget when recording them is slow or financial apps require accounts, subscriptions, or network access.

**Approach:** A polished Flutter expense tracker with entry management, category-based analytics, AMOLED-inspired dark and light themes, and local persistence.

**Technology:** Flutter · Dart · Provider · Shared Preferences · FL Chart · Google Fonts

**Data status:** Offline, device-local expense records; not encrypted storage or automatic multi-device backup.

[**Source code →**](https://github.com/svsramakrishnanaidu-rgb/fin-tracker) · [**App screenshots →**](https://github.com/svsramakrishnanaidu-rgb/fin-tracker#app-preview) · [Run locally →](https://github.com/svsramakrishnanaidu-rgb/fin-tracker#get-started)

**Public website:** Not yet published/verified in this GitHub repository. Do not confuse a Flutter web build target with a deployed site.
